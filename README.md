# GRIP — Green Reporting & Innovation Platform

Hackathon MVP: Python + Streamlit + SQLite + Gemini.

Core flow: **Report → AI Analyze → Discuss → Track → Innovate**

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Set `GEMINI_API_KEY` for live AI features. The app has fallback/demo mode without a key.

## Suggested demo
1. Report an environmental issue with photo/location/description.
2. Show AI-assisted analysis.
3. Open issue and add a community comment.
4. Update status.
5. Open Innovation Lab and generate a green solution/business idea.

GRIP does not claim that AI officially verifies reports or guarantees government action; AI output is advisory and needs human/local verification.
